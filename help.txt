hf

read config from current dir then start running


hf config

generate a default configuration file


hf config_file_path

i.e.  hf ~/.config/http-filter/config.json

hf help

print help manual



For all available API management endpoint, send request to http://config_serve_addr/api/text or http://config_serve_addr/api/html

Where the config_serve_addr load from config.json
